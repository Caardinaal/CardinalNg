# CardinalNG

کلاینت پیشرفته و بهینه‌شده بر پایه هسته Xray و SSH برای اندروید.

## ویژگی‌ها
- **دریافت هوشمند سرور:** گلچین تصادفی ۱۵ سرور غیرتکراری از مخازن اوپن‌سورس گیت‌هاب با حفظ کانفیگ‌های دستی کاربر
- **پشتیبانی بومی از پروتکل SSH:** امکان افزودن دستی (`Add [SSH]`) و ایمپورت/اشتراک‌گذاری مستقیم لینک‌های `ssh://`
- **ابزارهای کنترلی سریع:** تست پینگ واقعی، مرتب‌سازی خودکار بر اساس کمترین پینگ و حذف هوشمند سرورهای خراب
- **هسته بهینه:** شامل دیتابیس‌های مسیریابی ایران (`GeoIP` / `GeoSite`) بدون پکت‌لاس
